1. What is regression?

Predict a number (price, temperature), not a class label.

  • x = input we know
  • y = true number
  • ŷ = model prediction (goal: make ŷ close to y)

2. Linear model

ŷ = w₀ + w₁ · x Easy words: prediction = bias + weight × input

With more features:

ŷ = w₀ + w₁x₁ + w₂x₂ + w₃x₃ + ···
Neuron in easy words Multiply inputs by weights → add them → identity activation (keep the number) → that is ŷ.

3. Activation = identity

f(z) = z After the weighted sum, keep the value as-is. Needed because targets can be any real number.

4. Loss J

e = ŷ − y one row contribution uses (1/2) e² Class total loss: J = (1/N) Σ (1/2)(ŷ − y)² = (1/(2N)) × (sum of squared errors) Goal: choose w₀, w₁ to make J small.

5. Gradient descent (learning loop)

  1. Compute ŷ for every row
  2. Compute Loss J
  3. Compute ∂J/∂w₀ and ∂J/∂w₁
  4. Update weights
w₀ ← w₀ − η · (∂J/∂w₀) w₁ ← w₁ − η · (∂J/∂w₁) Why minus? ∂J/∂w points uphill on Loss. Subtract to walk downhill.

Gradient formulas (exact math)

For each row: e = ŷ − y ∂J/∂w₀ = (1/N) Σ e ∂J/∂w₁ = (1/N) Σ (e · x) (Same as class matrix form: ∇J = (1/N) Xᵀ e )

6. When to stop

Stop if 1. Gradients almost zero: |∂J/∂w₀| and |∂J/∂w₁| very small
2. Loss J barely changes between steps
3. Max iterations reached (e.g. 1000)
4. Validation loss rises (early stopping)
  • η too big → Loss jumps / explodes
  • η too small → very slow learning
  • Try η ∈ {0.001, 0.01, 0.1, 1.0}

7. Class worked example

Predict price from size. η = 0.1 , N = 3.

Rowx (size)y (price)
112
224
335

Model: ŷ = w₀ + w₁ · x

Start

w₀ = 0 w₁ = 0

Step A — Predictions ŷ

ŷ₁ = 0 + 0·1 = 0 ŷ₂ = 0 + 0·2 = 0 ŷ₃ = 0 + 0·3 = 0

Step B — Errors e = ŷ − y

e₁ = 0 − 2 = −2 e₂ = 0 − 4 = −4 e₃ = 0 − 5 = −5

Step C — Loss J

Σ e² = (−2)² + (−4)² + (−5)² = 4 + 16 + 25 = 45 J = 45 / (2·3) = 45/6 = 7.5

Step D — Gradients ∂J/∂w₀ and ∂J/∂w₁

∂J/∂w₀ = (1/3)[(−2)+(−4)+(−5)] = (1/3)(−11) = −3.67 ∂J/∂w₁ = (1/3)[(−2)·1 + (−4)·2 + (−5)·3] = (1/3)[(−2)+(−8)+(−15)] = (1/3)(−25) = −8.33

Step E — Update

w₀ ← 0 − 0.1 · (∂J/∂w₀) = 0 − 0.1·(−3.67) = 0.367 w₁ ← 0 − 0.1 · (∂J/∂w₁) = 0 − 0.1·(−8.33) = 0.833

Step F — New ŷ and new J

ŷ₁ = 0.367 + 0.833·1 = 1.20 ŷ₂ = 0.367 + 0.833·2 = 2.03 ŷ₃ = 0.367 + 0.833·3 = 2.87 new errors ≈ −0.80, −1.97, −2.13 new J ≈ 1.51 Loss fell: 7.5 → 1.51 Repeat until stop rule.

8. Evaluation (short)

MSE = average of (ŷ − y)² RMSE = √MSE MAE = average of |ŷ − y| R² ≈ 1 perfect; 0 = like predicting mean y; 0.7–0.9 often good Always check on test data (unseen rows).
