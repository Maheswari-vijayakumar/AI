# Mode

## What is Mode?

The **Mode** is the value that appears **most frequently** in a dataset.

In simple words, it is the value that occurs **more times than any other value**.

Unlike the mean and median, the mode does **not** depend on the position or the sum of the values. It only depends on **how often a value appears**.

---

## How to Find the Mode?

1. Arrange the data (optional, but makes it easier to identify repeated values).
2. Count how many times each value appears.
3. The value with the **highest frequency** is the mode.

---

## Example

Suppose the marks of eight students are:

```text
50, 60, 70, 70, 80, 90, 70, 100
```

Count the frequency of each value.

| Marks | Frequency |
|-------:|----------:|
| 50 | 1 |
| 60 | 1 |
| 70 | 3 |
| 80 | 1 |
| 90 | 1 |
| 100 | 1 |

The value **70** appears **3 times**, which is more than any other value.

**Answer**

```text
Mode = 70
```

---

## Can a Dataset Have More Than One Mode?

Yes.

### Two Modes (Bimodal)

```text
10, 20, 20, 30, 30, 40
```

Both **20** and **30** appear twice.

```text
Mode = 20 and 30
```

This is called a **Bimodal** dataset.

---

### More Than Two Modes (Multimodal)

```text
10, 10, 20, 20, 30, 30
```

All three values appear twice.

```text
Mode = 10, 20 and 30
```

This is called a **Multimodal** dataset.

---

### No Mode

If every value appears only once, there is **no mode**.

Example:

```text
10, 20, 30, 40, 50
```

Since no value repeats,

```text
Mode = No Mode
```

---

## Outliers and Mode

Let's look at an example.

Dataset:

```text
50, 60, 70, 70, 80
```

Mode:

```text
70
```

Now replace **80** with **500**.

```text
50, 60, 70, 70, 500
```

The mode is still:

```text
70
```

The outlier does not change the mode because it only appears once.

For this reason, we say:

> **The mode is not affected by outliers.**

---

## Advantages

- Easy to find and understand.
- Not affected by outliers.
- Can be used for both numerical and categorical data.
- Helps identify the most common value in a dataset.

---

## Limitations

- Some datasets have no mode.
- Some datasets have multiple modes.
- Does not consider every value in the dataset.

---

## Key Points

- Mode is the value that appears most frequently.
- A dataset can have one mode, multiple modes, or no mode.
- Mode is not affected by outliers.
- It is useful when we want to find the most common value in a dataset.
