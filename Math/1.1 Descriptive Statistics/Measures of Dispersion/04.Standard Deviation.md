# Standard Deviation

## Why Do We Need Standard Deviation?

In the previous section, we learned about **Variance**.

Variance measures how spread out the data is by using every value in the dataset.

However, variance has one major limitation.

The result is measured in **squared units**.

For example, if the data represents marks, the variance is measured in **marks²**, which is difficult to understand.

To solve this problem, we use **Standard Deviation**.

Standard deviation is simply the **square root of the variance**.

Because we take the square root, the result is expressed in the **same unit as the original data**, making it much easier to interpret.

---

## What is Standard Deviation?

**Standard Deviation (SD)** is a measure of dispersion that tells us **how far the data values are from the mean, on average**.

A:

- **Small Standard Deviation** means the values are close to the mean.
- **Large Standard Deviation** means the values are spread far away from the mean.

---

## Formula

Standard deviation is the square root of the variance.

```text
Standard Deviation = √Variance
```

---

## Example

Suppose we have the following dataset:

```text
10, 20, 30, 40, 50
```

From the previous section, we already calculated:

```text
Variance = 200
```

Now calculate the standard deviation.

### Step 1

Take the square root of the variance.

```text
Standard Deviation = √200

≈ 14.14
```

**Answer**

```text
Standard Deviation ≈ 14.14
```

## Understanding Standard Deviation

Imagine two classrooms.

### Classroom A

```text
48, 49, 50, 51, 52
```

Mean:

```text
50
```

The students' marks are very close to the mean.

So,

```text
Standard Deviation = Small
```

---

### Classroom B

```text
10, 20, 50, 80, 90
```

Mean:

```text
50
```

The marks are spread far away from the mean.

So,

```text
Standard Deviation = Large
```

---

## Why is Standard Deviation Better than Variance?

Suppose the marks of students are measured in **points**.

Variance:

```text
200 points²
```

This unit (**points²**) is difficult to interpret.

Standard Deviation:

```text
√200 ≈ 14.14 points
```

Now the answer is in **points**, which is much easier to understand.

This is why data scientists usually prefer **Standard Deviation** over **Variance**.

---

## Advantages

- Uses every value in the dataset.
- Easy to interpret because it uses the original unit.
- Widely used in statistics, machine learning, and data science.
- Helps compare the spread of different datasets.

---

## Limitations

- Affected by outliers.
- Slightly more difficult to calculate than Range or IQR.

---

## Key Points

- Standard Deviation is the square root of Variance.
- It measures how far the values are from the mean.
- Small SD means the data is close to the mean.
- Large SD means the data is widely spread.
- It uses the same unit as the original data, making it easier to understand.
